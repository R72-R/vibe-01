# 学习打卡清单

一个单文件的网页小工具，用来记录每天想完成的学习任务。不用安装任何东西，也不用联网。

## 能做什么

- 输入一条任务，点「添加」或者按回车，就加进清单
- 勾选表示完成，文字会加上删除线
- 每条右边有「删除」按钮，可以单独删掉
- 清单上方显示「已完成 X / Y 条」，随手勾一下就能看到推进了多少
- 数据存在浏览器本地，刷新页面后还在

## 怎么打开使用

1. 打开文件资源管理器，进入这个文件夹
2. 双击 `index.html`，它会用浏览器打开
3. 在输入框里写一条今天要完成的事，点「添加」

## 怎么确认它没坏

自动检查（几秒钟，需要装过 Node.js）：

1. 在这个文件夹的地址栏里输入 `cmd` 回车，开一个终端
2. 执行 `node verify.js`
3. 看到「25 项通过，失败 0 项」就是好的；有失败项会列出实际值和期望值

自动检查覆盖逻辑：增删改查、计数、存档读写、坏数据兜底。它看不出版式和布局，所以下面这步不能省。

人工验收（打开页面，按顺序点一遍）：

1. 清单为空时，统计行不出现，页面显示「还没有条目」
2. 输入「背单词」回车，统计变成「已完成 0 / 1 条」
3. 再输入「写周报」，变成「已完成 0 / 2 条」
4. 勾上「背单词」，变成「已完成 1 / 2 条」，文字出现删除线
5. 取消勾选，回到「已完成 0 / 2 条」
6. 两条都勾上，变成「已完成 2 / 2 条」，按 F5 刷新后仍然是「2 / 2」
7. 删掉一条，变成「已完成 1 / 1 条」
8. 删完，回到空清单，统计行消失
